1. Produit tensoriel et états composites

Quand on combine plusieurs systèmes quantiques, on utilise le produit tensoriel pour construire l'espace d'état global. Pour deux qubits, l'espace est 4-dimensionnel.

⊗ Produit tensoriel

L'espace de Hilbert d'un système composé est le produit tensoriel des espaces individuels :

$$\mathcal{H}_{\text{total}} = \mathcal{H}_A \otimes \mathcal{H}_B$$

Un état produit s'écrit comme :

$$\ket{\psi} = \ket{\psi_A} \otimes \ket{\psi_B} = \ket{\psi_A\psi_B}$$

1.1 Notation et dimension

Pour deux qubits, la base computationnelle est :

$$\{\ket{00}, \ket{01}, \ket{10}, \ket{11}\}$$

Cet état de 4 dimensions peut être écrit comme :

$$\ket{\psi} = \alpha_{00}\ket{00} + \alpha_{01}\ket{01} + \alpha_{10}\ket{10} + \alpha_{11}\ket{11}$$

avec $\sum_{i,j} |\alpha_{ij}|^2 = 1$.

2. Intrication quantique (Entanglement)

Un état est intriqué s'il ne peut pas être écrit comme un produit tensoriel d'états individuels. Les qubits deviennent correlated de façon non-classique.

2.1 États de Bell

Les états de Bell sont les quatre états maximalement intriqués de deux qubits :

$$\ket{\Phi^+} = \frac{1}{\sqrt{2}}(\ket{00} + \ket{11})$$ $$\ket{\Phi^-} = \frac{1}{\sqrt{2}}(\ket{00} - \ket{11})$$ $$\ket{\Psi^+} = \frac{1}{\sqrt{2}}(\ket{01} + \ket{10})$$ $$\ket{\Psi^-} = \frac{1}{\sqrt{2}}(\ket{01} - \ket{10})$$

🔗 Propriétés de l'intrication

Dans un état de Bell, mesurer le qubit A détermine instantanément le résultat pour le qubit B, même s'ils sont séparés spatialement. C'est la corrélation quantique non-locale.

2.2 Distinguabilité

Contrairement aux états classiques, les états de Bell ne peuvent pas tous être distingués avec certitude par une mesure locale. C'est l'impossibilité de la discrimination LOCC (Local Operations and Classical Communication).

3. Les inégalités de Bell et la non-localité

Bell a démontré que les corrélations quantiques ne peuvent pas être reproduites par une théorie classique avec variables cachées locales. C'est le test de Bell.

3.1 Inégalité de Bell

Pour une théorie classique locale avec variables cachées :

$$|S| \leq 2$$

où $S$ est la combinaison de quatre corrélations de mesure. Mais en mécanique quantique :

$$|S|_{\text{quantum}} \leq 2\sqrt{2} \approx 2.83$$

Cette violation est une preuve expérimentale que la nature est non-locale.

🌌 Implications philosophiques

La violation des inégalités de Bell signifie que :

  • Les résultats de mesure ne sont pas prédéterminés par des variables cachées locales
  • La nature est intrinsèquement probabiliste
  • Les mesures sur un qubit affectent instantanément l'autre (corrélation non-locale)
  • La réalité quantique n'est pas classiquement réaliste

4. Information quantique et qubits

Un qubit est l'unité fondamentale d'information quantique. Contrairement aux bits classiques (0 ou 1), un qubit peut être en superposition.

4.1 Avantages informatiques

  • Superposition : $n$ qubits peuvent représenter $2^n$ états simultanément
  • Parallélisme quantique : Les calculs explorent tous les états à la fois
  • Intrication : Crée des corrélations impossibles classiquement
  • Interférence : Les amplitudes s'additionnent et s'annulent

4.2 Limites du qubit

Malgré ses avantages :

$$\text{Pas de clonage quantique : impossible de copier un qubit arbitraire}$$

Et on ne peut extraire qu'un seul bit d'information classique d'une mesure d'un qubit (Théorème de Holevo).

5. Résumé et concepts clés

🎯 Points essentiels

  • Produit tensoriel : Combine les espaces de systèmes individuels
  • Intrication : États non-séparables avec corrélations non-locales
  • États de Bell : Quatre états maximalement intriqués de deux qubits
  • Inégalités de Bell : Prouvent que la non-localité est réelle
  • Parallélisme quantique : $n$ qubits explorent $2^n$ états simultanément
  • Information quantique : Nouvelle ressource exploitée par le calcul quantique
