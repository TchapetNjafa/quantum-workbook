États quantiques et fonctions d'onde

De la description abstraite aux fonctions d'onde : potentiel, énergie et confinement

1. Représentations en mécanique quantique

Le même état quantique peut être représenté de différentes façons selon la base choisie. Les deux bases principales sont la représentation de position et la représentation d'impulsion.

1.1 Représentation de position

Dans cette représentation, l'état est décrit par la fonction d'onde $\psi(x)$ : l'amplitude de probabilité de trouver la particule à la position $x$.

$$|\psi(x)|^2 \, dx = \text{probabilité de trouver la particule entre } x \text{ et } x + dx$$

La condition de normalisation s'écrit :

$$\int_{-\infty}^{\infty} |\psi(x)|^2 \, dx = 1$$

1.2 Représentation d'impulsion

On peut aussi exprimer l'état en termes d'impulsion via la transformée de Fourier :

$$\phi(p) = \frac{1}{\sqrt{2\pi\hbar}} \int_{-\infty}^{\infty} e^{-ipx/\hbar} \psi(x) \, dx$$

Où $|\phi(p)|^2$ est la densité de probabilité pour trouver l'impulsion $p$.

🔄 Relation d'incertitude de Fourier

Les largeurs des distributions en position et impulsion sont liées par :

$$\Delta x \cdot \Delta p \geq \frac{\hbar}{2}$$

Une fonction bien localisée en position est diffuse en impulsion, et vice-versa.

2. L'équation de Schrödinger indépendante du temps

Pour les états stationnaires (énergie définie), on résout l'équation d'onde indépendante du temps :

$$-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} + V(x)\psi(x) = E\psi(x)$$

⚙️ Structure de l'équation

Terme cinétique : $-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2}$ (énergie due au mouvement)

Terme potentiel : $V(x)$ (interaction avec l'environnement)

Énergie totale : $E$ (valeur propre)

2.1 Conditions aux limites et confinement

La fonction d'onde doit être continue, à variation continue, et s'annuler à l'infini (ou aux limites du confinement). Ces conditions quantifient les énergies autorisées.

Types de potentiels courants :

  • Particule libre : $V(x) = 0$ (pas de confinement)
  • Boîte infinie : $V(x) = 0$ pour $0 < x < L$, $V = \infty$ ailleurs
  • Oscillateur harmonique : $V(x) = \frac{1}{2}m\omega^2 x^2$
  • Puits fini : $V(x)$ constant à l'intérieur, constant plus haut aux bords

3. Particule dans une boîte

Le système le plus simple résolvable analytiquement. Une particule confinée dans un puits infini exhibe la quantification de l'énergie.

3.1 Niveaux d'énergie

Les énergies autorisées sont quantifiées :

$$E_n = \frac{n^2\pi^2\hbar^2}{2mL^2}, \quad n = 1, 2, 3, \ldots$$

L'énergie du niveau fondamental ($n=1$) n'est jamais zéro : énergie de point zéro.

$$E_1 = \frac{\pi^2\hbar^2}{2mL^2}$$

3.2 Fonctions d'onde

$$\psi_n(x) = \sqrt{\frac{2}{L}} \sin\left(\frac{n\pi x}{L}\right)$$
  • Le niveau fondamental ($n=1$) a une seule "bosse" (pas de nœuds intérieurs)
  • Le premier excité ($n=2$) a un nœud au centre
  • Le nième état a $(n-1)$ nœuds intérieurs
  • Plus $n$ est grand, plus l'énergie augmente (quadratiquement)

4. Oscillateur harmonique quantique

L'oscillateur harmonique est fondamental : on le rencontre en optique quantique, en physique des solides, en théorie des champs. Son potentiel est parabolique.

$$V(x) = \frac{1}{2}m\omega^2 x^2$$

4.1 Niveaux d'énergie

Les énergies sont :

$$E_n = \left(n + \frac{1}{2}\right)\hbar\omega, \quad n = 0, 1, 2, \ldots$$

Contrairement à la boîte, les niveaux sont régulièrement espacés (séparation $\hbar\omega$), et il existe une énergie de point zéro même pour $n=0$ : $E_0 = \frac{1}{2}\hbar\omega$.

4.2 Algèbre de l'oscillateur : opérateurs création/annihilation

Au lieu de résoudre l'équation différentielle, on peut utiliser l'algèbre. On définit les opérateurs :

$$\hat{a} = \sqrt{\frac{m\omega}{2\hbar}}\hat{x} + i\sqrt{\frac{1}{2m\omega\hbar}}\hat{p}$$ $$\hat{a}^\dagger = \sqrt{\frac{m\omega}{2\hbar}}\hat{x} - i\sqrt{\frac{1}{2m\omega\hbar}}\hat{p}$$

🎺 Propriétés des opérateurs

  • $\hat{a}^\dagger\hat{a}\ket{n} = n\ket{n}$ : opérateur nombre
  • $\hat{a}^\dagger\ket{n} = \sqrt{n+1}\ket{n+1}$ : crée une excitation
  • $\hat{a}\ket{n} = \sqrt{n}\ket{n-1}$ : annihile une excitation
  • $\hat{H} = \hbar\omega(\hat{a}^\dagger\hat{a} + \frac{1}{2})$

5. États cohérents et états de Fock

Dans l'optique quantique, on rencontre deux types d'états fondamentaux :

5.1 États de Fock (états de nombre)

Les états propres de l'oscillateur : $\ket{n}$. Ils ont un nombre exact de photons/excitations.

  • États purs : Pas d'incertitude sur le nombre de photons
  • Propriété : $\hat{a}^\dagger\hat{a}\ket{n} = n\ket{n}$
  • Orthogonaux : $\langle m | n \rangle = \delta_{mn}$

5.2 États cohérents

Définis par :

$$\ket{\alpha} = e^{-|\alpha|^2/2} \sum_{n=0}^{\infty} \frac{\alpha^n}{\sqrt{n!}}\ket{n}$$
  • États classiquement ressemblants : Minimisent l'incertitude quantique
  • Propriété : $\hat{a}\ket{\alpha} = \alpha\ket{\alpha}$
  • Non-orthogonaux : $\langle \alpha | \beta \rangle = e^{-|\alpha - \beta|^2/2} \neq 0$
  • Lumière laser : La lumière laser est dans un état cohérent

6. Résumé et concepts clés

🎯 Points essentiels

  • Fonction d'onde : Amplitude de probabilité en représentation de position

  • Particule dans une boîte : Exemple simple de quantification d'énergie
  • Oscillateur harmonique : Système fondamental avec niveaux régulièrement espacés
  • Opérateurs création/annihilation : Outils puissants pour résoudre les systèmes
  • États cohérents : Les plus classiquement ressemblants, décrivent la lumière laser
